⚙️ Première installation (administrateur)

Pour partager le planning entre tous les formateurs, connectez une base Firebase (gratuite) :

  1. Allez sur console.firebase.google.com → « Ajouter un projet »
  2. Dans le projet : Créer → Realtime Database → « Créer une base » → mode test
  3. Paramètres du projet ⚙️ → « Vos applications » → icône Web </> → enregistrer l'application
  4. Copiez le bloc firebaseConfig et collez-le ci-dessous
